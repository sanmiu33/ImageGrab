为什么需要「图提取」？

电商运营每天都要和详情页图片打交道，但这些图片总是拿得不顺手。

图片分散在各处

主图、细节图、SKU 图散落在轮播、懒加载和 CSS 背景里，右键另存为一张张点到手软。

无法批量保存

浏览器自带的「另存为」只能逐张操作，也没有进度提示，一张详情页动辄几十张图。

格式五花八门

平台为了省流量下发 WebP、AVIF，Windows 常常打不开。「图提取」统一转成 PNG，双击即看。

核心功能

六个能力，覆盖从提取到落盘的完整流程。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src 等各类懒加载写法与 CSS 背景图。

智能过滤

自动排除图标、logo、占位图与埋点小图，同一张原图的多档缩略变体只保留最大的一张。

集中预览

提取结果在新标签页网格展示，每张图标注真实尺寸，响应式布局大屏小屏都好看。

自由勾选

全选、反选、单点切换，实时统计已选数量，要哪几张点哪几张。

统一 PNG

无论原图是 JPG、WebP 还是 AVIF，都通过 Canvas 重编码为真正的 PNG，Windows 双击即开。

批量下载

一键保存到浏览器默认下载目录，文件名自动补零编号（商品图_001.png），带实时进度反馈。

四步完成安装

无需应用商店审核，开发者模式直接加载，全程不到一分钟。

  1. 1

    下载并解压插件

    下载插件压缩包并解压到本地任意文件夹，记住解压路径。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载插件文件夹

    点击「加载已解压的扩展程序」，选择解压后的文件夹，完成！
